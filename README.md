# Tarea-Computo-de-alto-desempeño

\# Tarea #998 – Bitácora



\### 15 de agosto de 2025

\- \*\*Tema:\*\* Alta disponibilidad y balanceo de carga  

\- \*\*Apuntes:\*\*  

&nbsp; - Conceptos de \*\*RAID\*\* y diferencias entre acceso público y privado.  

&nbsp; - Balanceadores de carga: uso de \*Keepalived\* y algoritmos de distribución (Round Robin, Round Weighted y basados en contexto).  

&nbsp; - Balanceadores en \*\*AWS\*\*: Application LB, Network LB (TCP/UDP) y Classic LB.  

&nbsp; - Arquitectura de tres niveles: Frontend, Backend y capa de transporte/red.  

&nbsp; - Contenedores: Docker, LXC, Podman y Kubernetes como orquestador.  

\- \*\*Observación:\*\* Se analizaron soluciones de alta disponibilidad y técnicas de distribución de tráfico.



\### 20 de agosto de 2025

\- \*\*Apuntes:\*\*  

&nbsp; - Definición de \*\*Cluster\*\* y tipos: HA (alta disponibilidad), LB (balanceo de carga), HPC (alto rendimiento).  

&nbsp; - Claves \*\*SSH\*\* para conexiones seguras entre nodos.  

&nbsp; - Herramientas utilizadas: Visual Studio Code, Git Bash y Markdown.  

&nbsp; - Secuencia de encendido y apagado de nodos y la importancia de BCP y DR para continuidad del negocio.  

\- \*\*Observación:\*\* Relevancia de la seguridad y la continuidad operativa mediante clusters.
